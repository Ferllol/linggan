Dreamcore (梦核): 唤醒童年潜意识的超现实美学，常用柔和光晕、眼球、无逻辑草地与轻微不安感的梦境场景。

Weirdcore (怪核): 梦核的攻击性版本，以低保真画质（Lo-Fi）、扭曲暗影、反逻辑拼贴和强烈的视觉失真来制造精神失常感。

Liminal Space (阈限空间美学): 聚焦过渡性、空无一人的物理空间（如走廊、空房间），利用孤独与诡异的熟悉感。

Poolcore (泳池核): 专注于无尽室内水域、蓝白马赛克磁砖、回音与死寂清澈水面的空间美学。

The Backrooms (后室核): “跌出现实”的无限黄色迷宫，泛黄壁纸、潮湿地毯与闪烁荧光灯的极端恐怖化空间。

Traumacore (创伤核): 带有早期互联网贴图、文本对话框与隐喻童年心理创伤的视觉风格。

Glitchcore (故障艺术核): 以数字撕裂、像素错位、高饱和度色彩与刺眼闪烁为特征的数字混乱美学。

Vaporwave (蒸汽波): 充满怀旧与消费主义讽刺，常用早期电脑图形、古希腊雕塑、粉紫霓虹色调。

Mallsoft (商场软核): 蒸汽波的建筑分支，描绘废弃或打烊的80/90年代大型购物中心、空荡中庭与慢速商场音乐。

Nostalgiacore (怀旧核): 极致还原VHS录像带画质、色差边缘、噪点与时间戳，主打旧日重现的氛围。

Cassette Futurism (磁带未来主义): 70-80年代的模拟科技美学，满是米白色CRT显示器、笨重主机和成排磁带机。

Arcadecore (街机厅核): 80/90年代复古街机厅的黑暗空间，伴随屏幕荧光与循环演示音。

Frutiger Aero (弗鲁提格航空): 2000年代中期的UI美学，包含极光、水滴、拟物化图标以及自然与科技的结合。

Solarpunk (太阳朋克): 明亮的绿色未来主义，融合新艺术运动风格、茂密植被与清洁能源科技。

Cottagecore (乡村核): 浪漫化的田园生活，核心元素为碎花、复古茶具、手工艺品与温暖自然光。

Fairycore (仙女核): 充满魔法色彩的自然美学，包含蝴蝶、薄纱、闪粉与发光森林。

Goblincore (地精核): 与仙女核相对，崇尚泥土、青苔、亮晶晶的小石头、昆虫、骨头和略带凌乱的自然收集癖。

Forestcore / Woodcore (森林核): 纯粹聚焦于深林、木屋、雾气和浓郁植物气息的自然美学。

Watercore / Oceanbreeze (海洋/水核): 围绕深海、水族馆、蓝色幽光、海洋生物与潜水视角的湿润美学。

Wintercore / Snowcore (雪界核): 被大雪覆盖、失去色彩和声音的冰冷室外环境。

Dark Academia (暗黑学院风): 围绕古典文学与求知欲，视觉上充满哥特式建筑、旧羊皮纸、昏暗烛光与深棕色调。

Light Academia (光明学院风): 暗黑学院的明亮版，聚焦诗歌、艺术、明媚的米白色调、阳光洒满的窗台和浪漫主义。

Royalcore / Regalcore (皇室核): 极度奢华的宫廷美学，包含巴洛克/洛可可建筑、华丽长裙、金边镜子与烛台。

Gothcore (哥特核): 以黑色为主调、蕾丝、十字架、暗夜、吸血鬼传说与颓废浪漫主义为核心。

Vampirecore (吸血鬼核): 更加专注夜行生物、天鹅绒、暗红酒液、古堡与永生主题的垂直美学。

Bubblegum Punk (泡沫朋克): 将明亮泡泡糖色彩（明粉、亮蓝）与朋克文化的叛逆、解构精神结合。

Cybercore (赛博核): 经典的赛博朋克视觉延伸，聚焦义体、高科技低生活、霓虹与金属线缆。

Biopunk (生物朋克): 赛博朋克的变种，聚焦有机组织、基因改造、变异生物及机械与肉体的异化。

Skatercore (滑板核): 街头涂鸦、滑板场、宽松卫衣、叛逆与随性的千禧年青年文化。

Ravercore (锐舞核): 电子音乐派对文化，荧光棒、高饱和度色彩、夜店闪光灯与狂欢氛围。

Suburbiacore (郊区核): 深夜千篇一律的北美式郊区街道、昏黄路灯与人工修剪草坪的死寂感。

Hospitalcore / Medicalcore (医院/医疗核): 废弃医疗空间、浅绿色长廊、无菌冷白光与潜意识对疾病的恐惧感。

Casinocore (赌场核): 无窗、无时钟、繁复迷宫地毯和空无一人老虎机的迷失感。

Cinemacore (影院核): 闭馆后的复古影院、红色天鹅绒座椅与巨大的熄灭荧幕。

Spacecore (深空舱内): 宇宙飞船或空间站的绝对封闭环境、生命维持系统与真空恐惧。

Librarycore (图书馆核): 无尽的书架、木质书桌、旧书纸张气味与绝对肃穆的安静空间。

Kitchencore / Diner core (厨房/餐厅核): 聚焦于复古的美式餐厅、格子桌布、煎盘滋滋作响的早晨，或是70年代风格、略带油烟气的温馨厨房。

Grandmacore / Grandcore (祖母核): 围绕舒适、怀旧的老年生活美学，包含针织毛衣、刺绣、老旧瓷器、烘焙点心与满屋的植物。

Clean Girl Core (洁净女孩核): 极简、清爽的现代生活方式美学，以梳得整齐的贴头皮发髻、裸妆、纯色运动服、晨间瑜伽和井井有条的极简空间为特征。

Coquette (洛丽塔/娇俏核): 以极度柔美、少女心为核心，充满蕾丝、蝴蝶结、芭蕾鞋、珍珠、粉白柔焦滤镜和法式复古浪漫。

Balletcore (芭蕾核): 围绕芭蕾舞艺术衍生的美学，包含缎带绑带鞋、紧身衣、薄纱蓬蓬裙、练功房的镜子与优雅的肢体线条。

Bakingcore (烘焙核): 专注于面粉、揉面、烤箱里的面包、黄油香气与温暖治愈的厨房慢生活。

Roadcore (公路核): 聚焦于无尽的沥青路面、车窗外的风景、加油站、汽车旅馆和“永远在路上”的流浪感与自由

Eldritchcore (克苏鲁/不可名状核): 聚焦于超越人类理智的古老神话、深海巨兽、触手、非欧几里得几何空间与令人战栗的宏大恐惧。

Truthanddarecore / Partycore (派对/狂欢核): 捕捉青少年派对后的余韵——散落的空酒瓶、揉皱的派对纸屑、凌乱的沙发和黎明前宿醉的空虚感。

Dollcore (人偶/娃娃核): 以精致但令人不安的陶瓷娃娃、关节球体人偶（BJD）、蕾丝洋装和空洞的眼神为核心，带有强烈的恐怖谷效应。

Gorecore / Splattercore (血浆/解剖核): 极具视觉冲击力的亚文化，将医学解剖图、复古恐怖片特效、假血浆和解构肉体作为主要视觉元素。

Kidcore (童真/儿童核): 极度饱和的色彩、90年代早期儿童电视节目元素（如彩虹熊、蜡笔画、贴纸）、塑料玩具与纯粹的童年怀旧。

Angelcore (天使核): 纯白羽翼、古典雕塑中的小天使（Putti）、圣洁的光芒、云朵与神圣的宗教浪漫主义。

Steelcore / Industrialcore (钢铁/重工业核): 冰冷的金属管道、火花四溅的电焊、液压机和无尽的重工业机械结构美学。

Analog Horror (模拟恐怖核): 模仿80/90年代电视广播遭黑客入侵或政府机密泄露的视觉风格，伴随严重失真的画面、警报声和诡异的紧急广播文本。

CGI Core / Early 3D Core (早期3D渲染核): 专门复刻90年代末至2000年代初粗糙、塑料感强、缺乏现代光线追踪技术的早期3D电脑动画与游戏画面风格。

Netcore (网络核): 围绕早期拨号上网、Windows 95/98界面、像素化图标、网景浏览器（Netscape）和原始BBS论坛的数字考古美学。

Loomcore (织物/编织核): 聚焦于织物纹理、羊毛、粗麻布、针织交错的细节与手工艺品的触感。

Ruincore (废墟核): 纯粹聚焦于人类建筑被时间侵蚀后的残骸。破碎的穹顶、坍塌的墙壁、钢筋外露的混凝土，展现人类文明痕迹消散的过程。

Skeletencore (骨骼核): 围绕动物或人类的骨骼、头骨、标本瓶、解剖学图谱展开的自然科学美学，带有一种冷静的死亡教育与生命标本感。

Taxidermycore (标本核): 比骨骼核更进一步，专注于动物剥制艺术、复古玻璃罩内的标本、标本鸟类和略带维多利亚式猎奇的自然收藏。

Abysscore (深渊核): 结合深海、无光层、海底热泉、地质裂谷与完全与世隔绝的极端黑暗地带，放大未知的宏大与孤独。

Nullcore (虚无核): 视觉上极致的“空”。没有色彩、没有几何物体、甚至没有光影，仅由纯粹的黑白灰构成的无垠虚空。

Witchcore (巫术核): 结合传统女巫传说，包含草药瓶、占卜塔罗牌、水晶、黑猫、月相变化、坩埚与森林中的神秘仪式感。

Cryptidcore (神秘生物核): 围绕都市传说与民间怪谈中的未解生物（如大脚怪、天蛾人、尼斯湖水怪），视觉上常伴有模糊的远景抓拍、森林夜视仪绿光和野外考察日记。

Tarotcore (塔罗核): 专属中世纪与现代神秘学的视觉符号，强调大阿尔卡那牌的几何构图、黄金分割、神秘符号、炼金术阵法与命运宿命感。

Folklorecore (民俗/民间传说核): 扎根于特定地域古老节庆、面具（如斯拉夫或欧洲的驱魔面具）、丰收祭典、篝火与原始部族的神秘狂欢。

Gorpcore (户外机能核): 将专业的户外登山、露营装备（如Gore-Tex冲锋衣、登山鞋、功能性背包）融入日常都市穿搭的实用主义美学。

Climbingcore / Boulderingcore (攀岩核): 聚焦室内攀岩馆的彩色岩点、镁粉、流汗的肌肉线条、攀岩鞋与坚韧挑战极限的青年文化。

Motocore / Biker-core (机车/摩托核): 经典的重机车、皮质夹克、复古头盔、机油味、高速公路与速度带来的反叛与自由。

Surfcore (冲浪核): 阳光、海浪、金色的沙滩、冲浪板、褪色的夏日防晒霜与充满自由不羁气息的海岸生活。

Goblin-merchant-core (地精商人核): 地精核的细分，专门收集亮闪闪的破烂、生锈的齿轮、偷来的金币、小瓶子和各种莫名其妙的奇珍异宝，充满囤积癖的可爱。

Mermaidcore / Sirencore (人海妖/美人鱼核): 鳞片、贝壳、珍珠、深海的长发、湿漉漉的渔网与海妖充满诱惑力的歌声神话。

Dragoncore (巨龙核): 专注于中世纪巨龙的巢穴、堆成山的金银珠宝、巨大的龙鳞、幽深的洞穴与炙热的龙息。

Steampunk-core (蒸汽朋克核): 维多利亚时期的工业革命美学，充满复杂的齿轮、黄铜仪表盘、蒸汽机、飞艇、护目镜与高礼帽。

Bratcore (泼辣/叛逆女孩核): 2024年爆红并延续至今的流行亚文化。以标志性的荧光亮绿色（Lime Green）、略显凌乱随意的涂鸦字体、宿醉后的狂欢派对感、不加修饰的真实与反精致主义为核心。

Shitpostcore (烂梗/抽象核): 彻底解构主流审美的网络狂欢，充满极度压缩的表情包、无厘头的拼贴、深奥的圈内梗和故意制作得粗糙诡异的视觉内容。

Webcore (网络/网页核): 怀念2000年代初个人博客（如MySpace、早期QQ空间）的时代记忆，包含闪烁的GIF挂件、非主流火星文、绚丽但凌乱的背景和原始网页设计。

Lo-Fi Core (低保真核): 刻意追求低分辨率、噪点、磁带失真和温暖的复古颗粒感，常伴随学习、雨夜、咖啡馆等放松而慵懒的氛围。

Bedroom Pop / Bedroomcore (卧室流行/卧室核): 极具松弛感的独立音乐与视觉美学。由乱糟糟但温馨的床铺、串灯（Fairy Lights）、贴满海报的墙壁、吉他和复古台灯构成的私人避难所。

Cozycore (舒适核): 所有能带来安全感与身体放松元素的集合：厚重的毛毯、热可可、壁炉的火光、猫咪、阴雨天和无限延长的慵懒午后。

Messycore / Cluttercore (杂乱美学核): 与极简主义完全相反，刻意保留满满当当的物品堆砌。书本、唱片、小摆件毫无规律却充满生活气息地占满每一个角落，展现极致的“有控制的混乱”。

Sleepcore / Dreamy Sleep (睡眠核): 聚焦于眼罩、丝绸睡衣、羽绒被、淡淡的薰衣草香气以及朦胧半梦半醒之间的温柔视觉。

Matchacore (抹茶核): 以治愈的深绿、抹茶粉、竹制茶筅、日式陶瓷茶碗以及清爽带有苦甜感的茶道生活方式为核心的美学。

Cafécore (咖啡馆核): 浓缩咖啡机（Espresso）的金属光泽、拉花、木质桌椅、空气中弥漫的咖啡豆香气和午后街景的交织。

Cottage-baking (田园烘焙核): 专注于刚出炉的面包、沾满面粉的手指、粗陶烤盘和浓郁的黄油与香草气息，充满原始的食物疗愈感。

Fruitcore / Berrycore (水果/浆果核): 鲜艳多汁的草莓、樱桃、切开的柑橘横截面。常伴随红白格桌布、清甜的夏日野餐和高饱和度的甜美色彩。

Y2K Cyber / Neo-Tokyo (新东京/千禧机能风): 融合了亚洲大都市夜景、高饱和度霓虹、机能风束脚裤、半透明防风面罩以及赛博朋克重工业质感的都市夜行美学。

Driftcore (漂移核): 聚焦于深夜的高速公路、日系老旧改装跑车（JDM）、尾灯拉出的红色光轨、轮胎摩擦的白烟与速度带来的肾上腺素飙升。

Techwearcore (暗黑机能核): 全身黑色的机能穿搭、无数的口袋、绑带、防水拉链、战术背心，强调在末日或现代都市中的绝对实用主义与冷酷利落感。

Salvagecore / Scrappycore (废品回收核): 崇尚用废旧零件、生锈铁皮、废弃电线和工业下脚料进行手工改造（DIY）的朋克式造物美学，充满末日废土的实用主义智慧。

Weldingcore / Sparks core (电焊与火花核): 专注于金属碰撞、刺眼的电弧光、飞溅的炽热火花、面罩与充满汗水和重工业气味的工厂车间。

Pipe-core / Plumbing-core (管道与水管核): 聚焦于密密麻麻错综复杂的工业管道、地下排水网、巨大的阀门与水流回声，带有强烈的幽闭与机械迷宫感。

Clockworkcore (钟表匠核): 极致精细的机械齿轮、游丝、发条、黄铜镊子与放大镜。聚焦于微小零件精密咬合的复古机械美学。

Terminalcore / CLI core (终端/命令行核): 纯粹由绿色或琥珀色单色字符组成的复古终端机界面（如老式Unix系统）、代码滚动、命令行输入提示符与纯粹的极客黑客氛围。

Warezcore / Crackcore (破解/盗版光盘核): 90年代末至2000年代初地下软件破解组（Warez Scene）的视觉风格。包含带有霓虹特效的自述文件（NFO ASCII Art）、激进的电子乐（Chiptune）、盗版光盘封面与反叛的数字地下情结。

Wireframecore (线框图核): 3D建模最初期的网格与多边形（Polygon）美学。没有材质贴图，只有裸露的白色或绿色几何线条构成的虚拟世界。

Liminal Horror / Uncannycore (阈限恐怖/恐怖谷核): 专门放大“熟悉事物变得不自然”所带来的精神恐慌。例如没有脸的人体模特、过度逼真但眼神空洞的机器、比例失调的日常家具。

Analog Archaism (模拟古物核): 结合了古代祭祀造物与现代失真电子媒介的矛盾美学，像是用VHS录像带记录下的远古不明仪式。

Parasitecore / Bioterrorcore (寄生与生物恐怖核): 聚焦于菌丝蔓延、肉体变异、虫群、寄生生物与有机体失控生长的科幻惊悚美学。

Rust Belt Core (铁锈地带核): 聚焦于美国中西部或全球老工业城市衰落后的景观：成排的红砖厂房废墟、空置的铁路调车场、阴冷的工业小镇与萧条的街景。

Motelcore (汽车旅馆核): 沿着美国公路开到深夜时落脚的廉价汽车旅馆。带有塑料感的印花床单、闪烁的霓虹灯招牌、冰柜里发光的自动售货机和极度短暂的过客感。

Oasiscore / Desertcore (荒漠/绿洲核): 极端干旱的黄沙、仙人掌、孤零零的公路、荒漠中的废弃加油站与被烈日炙烤的苍凉寂静。

Eastern Bloc Core / Post-Soviet (东欧/后苏联核): 独特的粗野主义混凝土住宅楼（赫鲁晓夫楼）、三条杠运动服（Adidas）、无尽的灰色冬天、工业重镇的萧条感与一种独特的斯拉夫哲学（Slavoj Zizek式或街头硬核）。

Eurotrashcore (欧式复古垃圾/夸张风): 90年代至2000年代初欧洲边缘地带的一种浮夸、廉价但极具视觉冲击力的时尚与派对美学，包含动物纹、金链子、复古跑车和高饱和度印花。

Nordic Noir (北欧黑色电影核): 极度寒冷的峡湾、终年不散的阴云、厚重的羊毛毛衣、冰冷沉闷的刑侦氛围与北欧极简主义的压抑结合。

Americana / Heartland Core (美国心脏地带核): 广阔的麦田、老旧的谷仓、复古加油机、乡村音乐、牛仔布与一种带着旧日荣光但正在消逝的美国乡村情结。

Shoegaze / Dreampop Core (鞋包/梦幻流行核): 视觉上呈现极度模糊、大面积的吉他效果器光晕、曝光过度的拍立得照片、沉溺于失真噪音与飘渺人声之中的迷幻朦胧感。

ASMRcore (感官触发核): 极致放大微小声音与触觉的视觉化。指甲敲击木头的特写、细腻的沙沙声、耳语麦克风、顺滑的液体流动与极其治愈的整理过程。

Noiseコア / Harsh Noise Core (噪音艺术核): 极具破坏性的视觉与听觉反叛。由密密麻麻的音频波形图、过载的混音台、错乱的电路板和极具实验性质的破坏性艺术构成。

Underpasscore / Bridgecore (立交桥底/桥梁核): 城市高架桥下巨大的水泥柱、斑驳的涂鸦、永不见阳光的阴暗角落、荒凉的停车空地与城市边缘的灰暗地带。

Staircasecore (楼梯间核): 专门聚焦于城市建筑中那些曲折盘旋、空无一人的消防楼梯、逃生通道、水泥台阶与密闭的垂直空间。

Rooftopcore (屋顶核): 城市建筑的最高处。错综复杂的排风管道、废弃的卫星天线、水塔、防雨油毡与俯瞰整个城市霓虹的孤独高空视角。

Bio-Mechanical Core (生物机械核): 深度致敬H.R. Giger（异形之父）的风格。将有机的生物肉体与冰冷的机械、骨骼、血管完美交织，形成一种宏大、诡异且充满生命力的异星造物美学。

Doll-Repair Core (人偶修复核): 专注于修复残破瓷娃娃的局部特写。白瓷碎片、细小的镊子、石膏、重新描绘的眼线与一种在残缺中寻找完美的怪异艺术感。

Taxidermy-Fantasy Core (奇幻标本核): 将现实中的动物标本进行超现实改造，比如给狐狸缝上翅膀、制作带有独角兽特征的骨骼标本，充满维多利亚科学怪人式的奇思妙想。
